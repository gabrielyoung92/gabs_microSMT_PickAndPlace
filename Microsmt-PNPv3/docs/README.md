Local setup and inspection records for the MicroSMT PNPv3 machine. These are
separate from the supplied [MicroSMT manuals](../README.md#manuals).

- [Setup status and remaining calibration](machine-setup-status.md)
- [OpenPnP commands and operating limits](openpnp-gcode.md)
- [Machine hardware and camera identification](MACHINE_HARDWARE.md)
- [Controller inspection and measured configuration](CONTROLLER_INSPECTION.md)
- [Two-nozzle vacuum sensor plan](vacuum-sensors.md) and [datasheet](datasheets/README.md)

`evidence/` retains the original controller/camera inspection logs. Private
session backups remain in the repository’s ignored `.local/v3-modding/` folder.
These dated records do not establish the machine’s present position or state.
