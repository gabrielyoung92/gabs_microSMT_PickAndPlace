STM32 FEEDER BUILDS
==================

V485: CURRENT MACHINE FIRMWARE 0.1.2
Open V485-feeder/CODE_feeder in PlatformIO or run from that folder:
  pio run -e v485

This builds the universal 8/12/16/24 mm application and automatically writes
V485-feeder/USB_host/firmware.json for the dashboard. Copy that bundle to the
machine host, then select Update or Update all outdated. Normal application
updates use the installed bootloader and preserve per-unit settings.

Source: V485-feeder/CODE_feeder/src/
Build configuration: V485-feeder/CODE_feeder/platformio.ini
Operating/build guide: V485-feeder/CODE_feeder/README.md
Initial ST-Link programming: V485-feeder/CODE_feeder/COMMISSIONING.md
Update protocol/tools: V485-feeder/CODE_feeder/BOOTLOADER.md
PC host/dashboard: V485-feeder/USB_host/README.md

The separate loader build is:
  pio run -e bootloader
It is for initial SWD programming; a normal application update leaves it alone.
Build does not upload. CubeMX/CubeIDE is not required.

V3 SOURCES
The V3 8 mm and V3 12/16/24 mm folders contain independent vendor SPL C programs,
not the universal V485 application. Each needs a matching STM32F1 SPL project,
startup code and linker configuration before it can build. See those folders'
README files. The V485 PlatformIO command does not build V3 sources.
