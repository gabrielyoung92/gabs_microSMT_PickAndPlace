# Working in this repository

- This is Gab's independent reorganisation of two MicroSMT collections. Read README.md, CREDITS.md and THIRD_PARTY_NOTICES.md first. Retain prominent upstream credit and supplied license notices.
- Canonical imported collections are Bing-feeder/ and Microsmt-PNPv3/. Generated previews and additional STL exports are local additions; they do not establish physical fit or hardware validation.
- Earlier custom firmware, KiCad recovery projects and machine notes are in _other/v3-modding/. Read its AGENTS.md before changing that project. Run its checks from that directory.
- Keep .local/ and generated build files ignored. Preserve the original Git metadata stored locally there.
- Do not commit, push, publish or change repository visibility unless the owner explicitly requests it. Keep the repository private until the owner explicitly requests public visibility.
- Keep private conversations, personal details and machine-specific local paths out of publishable documentation and metadata.
- File organisation does not authorize hardware flashing or machine operation.
