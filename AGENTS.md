# Working in this repository

- This is an independent reorganisation of two MicroSMT collections. Read
  README.md, CREDITS.md and THIRD_PARTY_NOTICES.md. Retain prominent upstream
  credit and supplied license notices.
- Canonical imported collections are Bing-feeder/ and Microsmt-PNPv3/.
  Generated previews and extra STL exports do not establish physical fit.
- Editable KiCad projects live beside their Gerbers. Recovery tools and editing
  limits are in tools/kicad/; read its AGENTS.md before changes.
- Machine setup records are in Microsmt-PNPv3/docs/.
- Keep .local/ and generated builds ignored. Preserve original Git metadata and
  private machine evidence stored locally there.
- Do not commit, push, publish or change repository visibility unless explicitly
  requested. Keep private conversations, personal details and machine-specific
  local paths out of publishable files and metadata.
- File organisation does not authorize hardware flashing or machine operation.
